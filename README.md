# AI 이완용 vs AI 독립군

Chrome 확장 프로그램에서 손짓으로 입력한 문장의 말투를 바꿀 수 있습니다.

확장 아이콘을 눌러 카메라를 켜고, 웹페이지 입력칸에 문장을 쓴 뒤 손짓을 해보세요. 바뀐 문장을 확인하고 직접 전송할 수 있습니다.

- 👍 엄지척 · 🫶 하트 · 🙏 두 손 모으기 → 공손한 말투
- 👎 엄지 아래 · 🖕 가운데 손가락 · 👊 주먹질 → 무례한 말투

팝업에서 `plz 지배 me`와 `일해라 ai` 테마도 고를 수 있습니다.

카메라 영상은 기기에서만 처리합니다. 문장은 말투를 바꿀 때 서버로 전송되며, Chrome 웹페이지의 입력칸에서만 바뀝니다.
