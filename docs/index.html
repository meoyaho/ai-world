카메라 손짓으로 입력 중인 문구 바꾸기

Gesture Prompt

엄지를 올리거나 내리면 지금 키보드 커서가 있는 입력칸에 설정한 문구를 추가합니다. VS Code의 Codex, 브라우저의 AI 채팅, 일반 입력칸에서 사용할 수 있습니다.

Mac 다운로드 · Apple Silicon Mac 다운로드 · Intel Windows 다운로드 · 64비트

사용 방법

  1. Mac에서는 ZIP을 풀고 GesturePrompt 앱을 엽니다. Windows에서는 EXE를 더블클릭합니다.
  2. Mac에서는 메뉴 막대의 🖐 아이콘에서 손쉬운 사용 권한을 허용하고 ‘카메라 켜기’를 누릅니다. Windows에서는 카메라 권한을 허용합니다.
  3. 문구를 넣을 입력칸을 클릭하고 엄지를 약 1초 유지합니다. 전송 버튼은 자동으로 누르지 않습니다.

알아둘 점

카메라 영상은 기기 안에서 손짓을 인식하는 데 사용합니다. 포커스가 코드 편집기나 다른 입력칸에 있으면 그곳에 문구가 들어갑니다. 초기 시험판은 운영체제의 앱 확인 경고가 나타날 수 있습니다.
