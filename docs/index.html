시작하기

세 단계면 충분합니다.

  1. 01

    확장을 설치합니다.

    아래 안내대로 Chrome에 Gesture Prompt를 추가하고 툴바에 고정합니다.

  2. 02

    카메라를 켭니다.

    툴바의 Gesture Prompt 아이콘에서 카메라 켜기를 누르고 권한을 허용합니다. 단축키는 Alt+Shift+G입니다.

  3. 03

    손짓을 합니다.

    웹페이지 입력칸에 문장을 쓴 채 손짓을 약 1초 유지합니다.
